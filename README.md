## Descripción del Proyecto

Este proyecto consiste en el diseño y desarrollo de un sitio web para el Instituto Politécnico. El objetivo principal es aplicar técnicas de maquetación para presentar la oferta académica, la estructura organizativa y las vías de contacto de la institución.

---

## Tecnologías Utilizadas

Para el desarrollo de este trabajo se emplearon las siguientes herramientas y lenguajes:

- **HTML:** Estructura semántica.
- **CSS & Bootstrap:** Estilos y diseño responsivo.
- **Git:** Control de versiones mediante el uso de ramas específicas para cada sección del proyecto.
